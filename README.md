# Happy People Static Fast

Это статическая версия приложения без npm, Next.js и package.json.

Для Vercel: загрузи все файлы в новый GitHub репозиторий и импортируй в Vercel. Framework Preset можно оставить Other/Static или Vercel определит сам. Сборка должна проходить быстро, потому что npm install не нужен.
